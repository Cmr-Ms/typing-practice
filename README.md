# 実用入力練習 (typing-practice)

ローマ字入力の速さだけを競う一般的なタイピングゲームとは違い、**変換を含む実際の日本語入力（実用入力）** を練習できるツールです。単一の HTML ファイルだけで動作し、サーバーは不要です。

- デモ: https://cmr-ms.github.io/typing-practice/
- 本体: [index.html](index.html)

## 使い方（基本の流れ）

1. [index.html](index.html) をブラウザで開く（またはデモページにアクセスする）。
2. 画面上部の緑色の大きい文字（出題文）を確認する。
3. その下の入力欄に出題文を入力する。
4. 最初の1文字を打った瞬間からカウントダウンが始まる。
5. 改行（Enter）すると、直前まで打った内容が出題文と完全一致していれば次の文へ進む。一致していなければ、そのまま同じ文にとどまる（何度でも打ち直せる）。
6. 制限時間（デフォルト60秒）が来ると自動でラウンドが終了し、結果（文字数・行数・ワード数）がアラートで表示されてリセットされる。

入力欄の背景色でリアルタイムに正誤が分かります。

| 背景色 | 意味 |
| --- | --- |
| 黒 | 未入力 |
| 濃い緑 | 出題文の先頭から正しく入力できている（途中経過） |
| 赤 | 出題文と食い違う文字を入力してしまった |

## 画面の各パーツ

| 表示・操作 | 説明 |
| --- | --- |
| 出題文（一番上の大きい文字） | 今から入力する文。 |
| 次の文（`次: ` の行） | 今の文を打ち終えた後に出題される文のプレビュー。 |
| 入力欄 | 実際に文字を入力するテキストエリア。 |
| 進捗表示 | これまでの入力文字数・行数・ワード数、Escapeで打ち切った「浪費した時間」の累計、現在の秒数設定における自己ベストスコアを表示。 |
| カウントダウン | 残り時間（秒）。 |
| ワード欄（大きいテキストエリア） | 出題される文章・単語のリスト。自由に書き換えられる（詳細は後述）。 |
| 「秒」入力欄 | 制限時間（デフォルト60秒）。値を変更すると即座にラウンドがリセットされる。 |
| 長文モード | ワード欄の解釈方法を切り替えるチェックボックス（後述）。 |
| ワード数モード | 秒数ではなく「ワード数」を条件にするチェックボックス（後述）。 |
| ワード固定 | 正解しても新しい文章・単語に切り替えず、同じ内容を繰り返し練習するためのチェックボックス。 |
| 「ワード」入力欄 | ワード数モードで目標とするワード数（デフォルト10）。 |
| リセットボタン | いつでも現在のラウンドを初期状態に戻す。 |
| 「追加のワードはこちらから」リンク | GitHub の [words](words) フォルダへのリンク。他の単語リストを閲覧・コピーできる。 |

## モードの詳細

### 通常モード（長文モードのチェックを外した状態）

- ワード欄に、改行区切りで単語や短文を1行ずつ書く（例: [words/e-typing kotowaza.txt](words/e-typing%20kotowaza.txt) のことわざリストなど）。
- 出題文はワード欄の行の中からランダムに1つ選ばれる。

### 長文モード（デフォルトでオン）

- ワード欄に、複数の「文章のまとまり」を**空行（改行2つ）区切り**で用意する。
- 各まとまりの中では、改行1つごとに1文として順番に出題され、次の文がプレビューに表示される。
- まとまりの最後の文まで打ち終えると、別のまとまりがランダムに選ばれて続く。
- 初期状態では、物語・社説・英文など複数のサンプル長文が読み込まれている。

### ワード数モード

- チェックすると、制限時間ではなく「ワード」を打ち終えた数を条件にする。
- 「ワード」欄で目標数を指定する（長文モードでは1つの文章のまとまりを打ち終えるごとに1ワードとしてカウントされる）。
- 目標数に到達すると、経過時間・文字/秒・文字/分がアラートで表示され、ラウンドがリセットされる。

### ワード固定

- チェックすると、文を正解しても新しい文章・単語セットに切り替わらず、同じ内容を繰り返し練習できる。
- 主に長文モードでの反復練習を想定した機能。

## スコアの記録

- 「最高スコア」は制限時間（秒数）の設定ごとにブラウザの `localStorage` に保存される。秒数を変えると別のスコア枠として記録される。
- 「浪費した時間」は Escape キーで途中リセットしたときの残り時間の累計。これも `localStorage` に保存され、ブラウザを閉じても引き継がれる。

## キー操作

- 通常の入力 + Enter（改行）で、その時点までの入力内容を出題文と照合し確定する。
- Escape キー: 現在のラウンドを中断してリセットする（残り時間が「浪費した時間」に加算される）。

## 単語リストの共有（URL パラメータ）

ワード欄の内容はページを再読み込みすると初期状態（デフォルトの長文サンプル）に戻ります。特定の単語セットを URL で共有したい場合は、`index.html` 内の `store_words` に登録されたプリセットを使えます。

```
https://cmr-ms.github.io/typing-practice/?word=maipaso202306a
```

`word` パラメータに指定できるプリセット名（現時点）:

- `maipaso202306a` / `maipaso202306b`（日本語のニュース・社説）
- `maipaso202306eb`（英語の社説）
- `maipaso202306ea`（英語の児童書抜粋）

新しいプリセットを追加したい場合は、`index.html` の `store_words` オブジェクトに `キー名: [長文モードかどうか(true/false), 本文]` の形で追記してください。

## words フォルダについて

[words](words) フォルダには、ことわざ・慣用句・擬音語擬態語などテーマ別の単語リストがテキストファイルとして置かれています。これらはアプリから自動読み込みはされないため、ファイルの中身をコピーしてワード欄に貼り付けて使用してください（1行1単語の通常モード用の書式です）。

自分で用意した単語リストを追加したい場合は、`words/` に新しいテキストファイルを追加して Pull Request を送ってください。

## ローカルでの動作

サーバーは不要です。[index.html](index.html) をブラウザで直接開くだけで動作します。
